## To start the bot

Docker is required for the mongo config. You will also need to reconfigure the emailjs if you want that working for your own, good luck.

1. `npm i`
2. Input your api key to `auth.json`.
3. `npm run start` OR `npm run fullStart` if you want the mongodb running.
